# BioComputation

Computational biology and bioinformatics projects: genomics, transcriptomics, molecular modelling and protein analysis.

## About this hub

This repository is an index. Each project lives in its own repository with its own code, tests, environment and results. The projects apply machine learning and data pipelines to public biological and chemical datasets, with attention to reproducibility and to the limits of what the data can support.

## Projects

| Project | What it does | Stack | Status |
|---|---|---|---|
| gene-expression-cancer-subtyping | Differential expression analysis plus machine learning classification of cancer subtypes | Python, scikit-learn | Planned |
| molecular-toxicity-prediction | Toxicity prediction from RDKit molecular features and a graph neural network | RDKit, PyTorch | Planned |
| protein-embeddings-classifier | Protein function classification from protein language model embeddings | PyTorch, ESM | Planned |
| pathogen-genomics-pipeline | Reproducible workflow for detecting drug-resistance markers in pathogen genomes | Biopython, Snakemake | Planned |
